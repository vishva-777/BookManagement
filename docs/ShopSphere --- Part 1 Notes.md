9. Product Controller

File:

src/main/java/com/example/shopsphere/controller/ProductController.java

Working controller:

package com.example.shopsphere.controller;

import com.example.shopsphere.entity.Product;
import com.example.shopsphere.repository.ProductRepository;
import org.springframework.web.bind.annotation.*;

import java.util.List;

@RestController
@RequestMapping("/api/products")
public class ProductController {

    private final ProductRepository productRepository;

    public ProductController(ProductRepository productRepository) {
        this.productRepository = productRepository;
    }

    @PostMapping
    public Product save(@RequestBody Product product) {
        return productRepository.save(product);
    }

    @GetMapping
    public List<Product> findAll() {
        return productRepository.findAll();
    }

    @PutMapping("/{id}")
    public Product update(@PathVariable Long id, @RequestBody Product product) {

        Product existingProduct = productRepository.findById(id)
                .orElseThrow(() -> new RuntimeException("Product not found"));

        existingProduct.setName(product.getName());
        existingProduct.setDescription(product.getDescription());
        existingProduct.setPrice(product.getPrice());
        existingProduct.setQuantity(product.getQuantity());
        existingProduct.setCategory(product.getCategory());

        return productRepository.save(existingProduct);
    }

    @DeleteMapping("/{id}")
    public String delete(@PathVariable Long id) {

        productRepository.deleteById(id);

        return "Product deleted successfully";
    }
}

20. Spring Security and the 401 Error

Spring Security was included as a dependency.

Initially, when POST was tested, the API returned:

401 Unauthorized

This happened because Spring Security's default security configuration
was protecting requests.

At this stage we had not yet implemented custom authentication or JWT.

For development/testing, we temporarily created a security configuration
that allows requests.

package com.example.shopsphere.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.web.SecurityFilterChain;

@Configuration
public class SecurityConfig {

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {

        http
                .csrf(csrf -> csrf.disable())
                .authorizeHttpRequests(auth -> auth
                        .anyRequest().permitAll()
                );

        return http.build();
    }
}

Important

This is a temporary development configuration.

The final application should not simply allow every request.

21. What is CSRF?

CSRF means:

Cross-Site Request Forgery

It is a web security concern involving unauthorized requests made using
a user's authenticated browser context.

For our current API development/testing setup, CSRF protection was
disabled:

csrf(csrf -> csrf.disable())

The security configuration will be revisited when we implement the final
authentication architecture.
